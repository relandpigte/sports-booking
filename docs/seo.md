# SEO operations for Bunal.club

The application publishes its canonical public URLs at `https://bunal.club`.
Technical SEO is generated by the Next.js metadata routes and page metadata:

- `/robots.txt` allows public pages and blocks private application/API paths.
- `/sitemap.xml` lists the homepage, hub directory, legal pages, and only hubs
  that are currently approved, payment-connected, and publicly bookable.
- Public pages use self-referencing canonical URLs. Filtered `/hubs` URLs point
  back to the canonical `/hubs` directory.
- Login, registration, dashboard, user-management, and blocked hub pages use
  `noindex` metadata.
- The homepage identifies Bunal.club as an Organization and WebSite using
  JSON-LD. Public hub profiles add BreadcrumbList and SportsActivityLocation
  data when the venue has a real address.
- Social shares use the generated 1200×630 Bunal.club Open Graph image.

## Google setup after deployment

1. Add `bunal.club` as a Domain property in Google Search Console and verify it
   with the DNS TXT record Google provides. DNS verification covers every
   protocol and subdomain and does not require an environment variable.
2. If DNS verification is unavailable, set `GOOGLE_SITE_VERIFICATION` in
   Vercel to the content value from Google's HTML meta tag, then redeploy.
3. Submit `https://bunal.club/sitemap.xml` in Search Console.
4. Inspect `/`, `/hubs`, and a live `/hubs/{id}` URL. Request indexing after
   Google confirms that the canonical and rendered page are correct.
5. Test live venue pages with Google's Rich Results Test. Only real, visible
   venue fields are included in the structured data.

## Content and local discovery

Technical metadata does not guarantee rankings. Each partner should provide a
unique venue description, complete address, phone number, operating hours,
current rates, and original court photos. Avoid copying the same description
between hubs.

Partners should maintain their own Google Business Profile and link its website
field to their public Bunal.club hub URL. Local sports organizations, tourism
pages, municipalities, and venue social profiles can also link to the relevant
hub page. These genuine local references are more useful than fabricated
listings or keyword-heavy filler.

Review Search Console's Pages, Enhancements, Core Web Vitals, and Performance
reports monthly. Use actual search queries and click-through data to improve
page copy rather than adding unsupported keywords.
